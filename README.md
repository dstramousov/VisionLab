# VisionLab

VisionLab — небольшая исследовательская лаборатория, в которой я пытаюсь разобраться, как языковая модель может воспринимать окружающий мир через обычную видеокамеру. Это не система видеонаблюдения и не попытка сделать очередной распознаватель предметов. Мне интересно, как из отдельных изображений постепенно возникает нечто похожее на непрерывное зрительное восприятие: способность замечать изменения, выделять важное, удерживать внимание на предмете и возвращаться к нему, когда он исчезает из поля зрения.

Обычная мультимодальная модель получает изображение и отвечает на вопрос о нём. Но живой мир не состоит из неподвижных фотографий. Предметы перемещаются, появляются и исчезают, перекрывают друг друга. Человек при этом не описывает заново всю комнату каждую секунду. Он может посмотреть на чашку, проследить за движением руки, заметить отсутствие вещи, которая только что была перед ним. Именно такие простые на первый взгляд способности хочется исследовать в этом проекте.

В основе VisionLab лежит связка локальной языковой модели Qwen3.5 и библиотеки OpenCV. Модель отвечает за понимание увиденного и поиск объекта по словесному описанию. OpenCV работает с видеопотоком и сопровождает найденный объект между обращениями к модели. Благодаря этому не нужно заставлять нейросеть анализировать каждый кадр. Если трекер теряет предмет, система может снова обратиться к модели и попытаться его найти.

Управлять вниманием можно обычным языком: попросить найти наручные часы, следить за кружкой, уточнить расположение предмета или описать происходящее перед камерой. При этом модель не получает произвольный доступ к компьютеру: она выбирает из предусмотренных программой операций, а их выполнение контролирует сам VisionLab. Для исследовательских экспериментов остаётся возможность управлять этими механизмами вручную.

Проект работает локально. Для получения изображения используется обычная USB-камера, для запуска модели — llama.cpp, а для взаимодействия с системой — браузер. Наблюдения при необходимости сохраняются в локальной базе SQLite. Исходные кадры, настройки и веса моделей не предназначены для публикации в репозитории.

Далеко не всё здесь работает идеально. Модель может ошибаться при определении границ предмета, а трекер — потерять объект или переключиться на похожий. Понимание изображения ещё не означает точного понимания пространства, а последовательность наблюдений сама по себе не создаёт память о мире. Эти ограничения и ошибки для меня не менее интересны, чем удачные результаты.

В дальнейшем хочется исследовать зрительную память, постоянство объектов, пространственные отношения, наблюдение за несколькими предметами и способность системы самостоятельно выбирать, на что обратить внимание. Не предполагается, что всё это уже решено. VisionLab — место для небольших воспроизводимых экспериментов, в которых можно проверить конкретную гипотезу, увидеть результат и понять, куда двигаться дальше.

История технических изменений ведётся отдельно в `CHANGELOG.md` и `versions.md`. Справка по работе с программой доступна в её интерфейсе.
